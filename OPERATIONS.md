# OPERATIONS MANUAL — Automated Fleet

*Day-to-day procedures. Project law, not constitutional law.*
*Amended by Tech Lead + Reviewer without escalation, if it doesn't conflict with higher law.*

---

## 1. Workflow

### Task Assignment

1. Tech Lead decomposes requirements into tasks.
2. Assigns to Implementers by capability and availability.
3. Determines parallelization per Constitution Article V and Subsidiary Law 005.

### Implementation Cycle

1. **Plan** — Review the task, check relevant interfaces (Article IV), plan approach. Broad latitude here.
2. **Execute** — Build within project law and frozen interfaces.
3. **Self-Review** — Verify compliance before submitting.
4. **Peer Review** — Reviewer evaluates. Interaction follows Subsidiary Law 001.
5. **Integrate** — Accepted work merges to main.

### Dependencies

1. If your task depends on another's output, wait — don't proceed on assumptions.
2. Report blockers to Tech Lead immediately for priority reassessment.
3. Idle time from real dependencies is acceptable (Article V).

---

## 2. Communication

1. All substantive technical discussion must be in writing.
2. Decisions from discussion get recorded as task comments, interface amendments, or precedent entries.
3. Implementers report progress at project-defined intervals.
4. Blockers reported immediately to Tech Lead.
5. Tech Lead maintains current project status visible to all Advocates.

---

## 3. Attorney General Reviews

1. All agents cooperate with retrospective reviews (Subsidiary Law 004).
2. Respond promptly when the AG requests information.
3. Right to defend per Constitution Article III.
4. When deviation is found: responsible agent proposes remediation. AG accepts or recommends alternatives. Persistent deviation escalates to Group Deciders.

---

## 4. Interface Management

1. All frozen interfaces recorded in project interface registry (name, spec, freeze date, dependents, amendment history).
2. Lifecycle: **Draft** (open to change) → **Frozen** (per Subsidiary Law 003) → **Amended** (per Subsidiary Law 003) → **Retired** (by agreement of all dependents).

---

## 5. Amending This Document

1. Tech Lead + Reviewer amend by mutual agreement.
2. Changes conflicting with Constitution or subsidiary laws are void.
3. Document changes with date and rationale.
